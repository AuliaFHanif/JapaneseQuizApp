# Japanese Kanji Quiz App

A minimalist, web-based Japanese Kanji reading and meaning quiz application designed to help learners practice their Kanji skills across all JLPT levels.

## Features

- **JLPT Levels:** Practice Kanji from N5 (beginner) up to N1 (advanced).
- **Difficulty Settings:** Choose between Easy, Medium, and Hard difficulty levels.
- **Customizable Quizzes:** Select the number of questions (10, 20, 50, or 100).
- **Word Categories:** Filter questions by part of speech (Verb, Noun, Adjective).
- **Quiz Modes:**
  - *Reading:* Test your ability to read the Kanji.
  - *Reading + Meaning:* Test both your reading and comprehension of the Kanji.
- **Stats Tracking:** Keep track of your progress and accuracy over time.
- **Leaderboards:** Compete and see how you rank against others.
- **Kanji Details:** Explore detailed information about specific Kanji.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your modern web browser.
3. Configure your quiz by selecting the JLPT level, difficulty, length, and mode.
4. Click **Start Quiz** to begin!

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

The application runs entirely in the browser and does not require a local server to play.
